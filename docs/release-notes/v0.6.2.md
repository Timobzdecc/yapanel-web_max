## yapanel-web_max 0.6.2 — Стабильные переходы YouTube Music, сохранение рекомендаций и 3D-эмулятор

Обновление поверх `v0.6.1`: исправлены обрывы и перескоки при переходах между треками YouTube Music, добавлена подстановка реальных ID треков Яндекс Музыки для сохранения рекомендаций, а в GitHub Pages и README появился интерактивный 3D-эмулятор панели.

### Что исправлено и добавлено

- **Чистые переходы треков в YouTube Music (без повтора начала прошлого трека):**
  - В `device/extmusic/hook_location.js` добавлено отслеживание `lastConsumedOverride`, а `GstBridge.play()` передаёт поколение потока `&gen=`, благодаря чему фоновый prefetch `com.yandex.io.sdk` больше не подхватывает повторно уже использованный `override_url.txt` с позиции `0:00`.
  - В `extmusic/gstbridge.py` повторный запрос `r_start == 0` больше не сбрасывает таймер позиции после запуска потока (`_stream_started`), а расчёт длительности использует `min(track_duration, streamer_dur)` при наличии обоих значений.
- **Защита от переключения панели на Яндекс Музыку и потери визуализатора / голоса:**
  - `ExtMusicService._is_yandex_auto_advance` теперь корректно распознаёт автопереход `com.yandex.io.sdk` по `playlistId` и `entityInfo.id` / `entityInfo.prev.id` (как с префиксом `track:`, так и без него на Станции Макс), не сбрасывая активное воспроизведение `ExtMusicService`.
- **Стабильное воспроизведение после голосовых команд:**
  - Добавлена синхронизация `ALICE_CANCEL_PATH` с диском и очистка просроченных окон подавления в `GstBridge`; в `hook_location.js` проверяются `seq > state.lastCancelSeq` и `Date.now() < state.ttsMuteUntil`; `_stop_yandex()` при активном `ExtMusicService` не вызывает `panel.music_cmd({"command": "stop"})`.
- **Подстановка реального ID трека Яндекс Музыки (сохранение рекомендаций «Моей волны»):**
  - Добавлен поиск текущего трека в каталоге Яндекс Музыки (`glagol.YandexMusic.find_track_id`) с нормализацией, проверкой длительности, сохранением чистых метаданных очереди (без перезаписи именем канала/аплоудера) и фолбэк-разбором названий вида `Artist - "Title" (Video)`. Найденный ID передаётся в `playMusic` в качестве несущего трека (при отсутствии в библиотеке Яндекса используется прежний фолбэк `153109827`).
- **Интерактивный 3D-эмулятор панели в браузере (GitHub Pages и README):**
  - Демо-стенд с 3D-моделью Станции Макс (`Three.js`), шуточным плеером на Web Audio с караоке, матрицей `25×16`, 10-полосным DSP-эквалайзером, светомузыкой Tuya и виртуальной root-консолью.

### Установка и обновление

1. **Windows:** скачайте архив релиза (или `install_to_max.ps1`), распакуйте и запустите **`install_to_max.bat`**.
2. **Обновление из веб-панели:** вкладка **«Настройки» → «Проверить обновления»**, после перезапуска обновите страницу в браузере (`Ctrl+F5`).
